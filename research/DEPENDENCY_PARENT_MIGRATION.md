# Collected-controller parent and wiring successor

2026-10-19. Evidence: static-inference and separately recorded offline-tested
invented inputs. English menus and native Wi-Fi FTP remain the primary goals.
This package repairs shared host-side verification; it establishes no camera
feature, exact-body correspondence, actual runtime qualification or write gate.

The frozen operational entry expects obsolete dependency receipts. Its saved
sources and evidence remain intact. A successor adapter now dispatches through
`tools/dependency_wiring.py` into the current collected controller and reconciles
saved output through `tools/dependency_parent.py`. The runtime entry and CLI stay
disabled. No operational activation packet is assembled by this adapter.

The parent recomputes all eleven dependency artifacts, hashes both controller
bridge envelopes, validates the independent start record against the original
operation and expectation, compares summary JSON values and hashes the exact
captured stdout bytes. Closed completion fields must retain the expected test
mode, release result and false authorization/feature/recovery/write claims.
The outer supervisor must separately establish terminal agreement, source and
packet freshness, namespace cleanup and expected callback/record metrics.
A controller exit code alone cannot establish a complete result.

Controller summaries legitimately contain finite nonnegative timing decimals.
Their parser rejects duplicate keys, nonfinite values, negative timing values,
floats outside fields ending in `seconds`, and excessive depth/node counts.
Other dependency and completion metadata keeps its stricter integer-only
grammar. This is not a replacement for the retained controller's semantic
summary validator or its bounded supervision.

The invented successor source closure has **62 roles**: the retained 58-role
fixture closure plus parent verifier, successor entry, successor wiring and
ordinary parent-helper loader. The child verifies every source buffer before
executing authored code; the dependency binding includes the complete closure
manifest. This is the derived invented roster, not an assumed operational count.

The parent verifier imports seven authored helpers from those exact checked
buffers using an explicit module-local import hook. It creates no `tools` aliases
and does not replace live imports. Top-level module bindings are checked before
and after verification. The retained parent validation loader still admits only
23 ordinary roles; the three protected roles stay out of that loader. Definitions
inside ordinary helpers are not permission to invoke protected functionality.

The retained entry is used only for ordinary invented-fixture planning. Its old
runtime wiring, old receipt verifier and extra child record owner are bypassed.
The collected controller owns its child record closure and callback release.
Parent cleanup retains the original error and makes one close attempt. Existing
bounded supervision and unknown-completion reconciliation remain unchanged.
Known child handles survive supervisor exceptions as unresolved observations;
the fallback performs no additional process action or automatic replay.
