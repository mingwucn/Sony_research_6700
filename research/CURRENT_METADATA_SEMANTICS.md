# Current prepared-request metadata semantics

RA-003; host-only, invented records. Evidence classes: static-inference and
offline-tested. English and native Wi-Fi FTP remain primary; looks stay deferred.

`tools/dependency_current_metadata.py` checks fourteen current ordinary records
against the same prepared request, checked dependency helpers and original
comparison context used by `dependency_launch_context`. The historical
forty-four-role validation remains comparison-only. No historical record is
rewritten to make its source-alias grammar cover the successor.

The prepared source map has 46 roles and 41 unique paths: 38 retained source roles,
six adapter entry roles sharing one file, and two explicit policy imports. Five
dependency helper buffers are bound separately from `closure_manifest`, whose
bytes are canonical JSON derived from that exact prepared source map. The derived
manifest is neither a Python module nor an independently opened source file.

| Current ordinary records | Checked relationship |
|---|---|
| Six basis records and historical evidence index | Original bytes equal the seven records already validated in the historical context. |
| Authored source manifest | Exact current source map, validated absolute root label, and derived closure kind/size/hash. |
| Authored source receipts | Exact 46-role coverage, source size/hash/path, typed read-only regular-file claims, stable stamps and completed read/close claims. |
| Dependency packet and fixed expectations | Equal the current prepared request; existing checked pure binder validates five helpers and derived closure against its dependency policy. |
| Activity scope | Original request hash, both current source record hashes, comparison context seal, protected descriptors, frozen limits and historical blockers. |
| Activity rights | Original scope hash, retained owner facts, five unresolved activity questions, pending decision and false authority flags. |
| Qualification index | Original byte receipts for the other thirteen records, current source-map digest, historical index digest and exact fourteen-role coverage. |

An external original-byte receipt set covers all fourteen current records.
Equivalent JSON with different bytes needs updated original-byte anchors; parsed
equality does not silently replace byte identity. Each ordinary record is limited
to 2 MiB. This is not a whole-process memory cap.

The six shared adapter roles must carry identical complete read claims. The same
device/inode pair cannot identify different paths. Single-link/non-reparse and
read-only claims are checked using the existing owned evidence validator. These
are supplied records, not new filesystem observations. Consistently rebinding a
synthetic root label does not establish a real directory's identity.

The caller owns metadata and adapter acquisition/cleanup and remains trusted.
Their checked buffers and live functions are checked before and after validation.
This module and its ordinary launch helper have not yet been added to the
isolated outer bootstrap's captured execution closure. The current suite runs
the actual authored fourteen-record comparison and pure dependency binder;
it does not launch an observer or execute installed third-party dependencies.

trust, operational rights and actual startup remain unestablished. The index is
