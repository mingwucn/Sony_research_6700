## Separate retrospective correction

`tools/dependency_cache_basis.py` checks the complete new localization result
against recomputation from supplied config/raw text and the declared source,
failure and file hashes. It requires exactly the measured true/true/false/true
pattern. Changed inputs, predicates, negative claims or source/failure bindings
refuse. Source/failure hashes are still caller declarations in this pure API.

It retains two typed quantities:

| Quantity | Basis and meaning |
|---|---|
| Original cache file-byte SHA-256 | Prior file-digest declaration; not a fresh file observation |
| Producer canonical-JSON-plus-newline SHA-256 | Self-report from the same saved raw record being compared; not an independent expectation |

The separate private `saved_comparison.py` binds thirteen fixed ordinary input
buffers before five pure authored helpers execute. Seven inputs are authored
source texts; the two producer sources are hashed only. Six are ordinary saved
metadata records, including the new localization. It keeps the original
descriptor audit projection, unchanged legacy adapter and retrospective helper.
It uses the producer's labeled canonical hash for that helper's cache expectation
and records the original file hash separately. An exclusive new output path
preserves the original refused attempt and prevents automatic replay.

This is a documented change to the retrospective expectation basis after the
diagnosis. It corrects a comparison across hash domains; it does not weaken the
unchanged adapter predicates or recover an independent historical expectation.
Three explicit blockers accompany it:

- `cache_expectation_is_same_saved_raw_record_self_report`
- `cache_file_and_canonical_content_relationship_unproved`
- `cache_contents_not_independently_revalidated`

All fourteen earlier legacy/retrospective blockers remain. Successful composition
therefore means supplied saved-record consistency with seventeen blockers. It
does not authenticate history, establish prior approval, apply the successor
guard/event contract, revalidate the entire descriptor audit, observe current
installation/cache contents, or authorize dependency/GDT execution.
