## Route and packet separation

The disposable child now composes the complete package collector, deterministic
proof transition and dependency producer. Its standalone bootstrap reads/checks
every authored source and packet buffer before executing the entry. Runtime
profile equality and CPython isolated/no-site/no-bytecode/optimization-zero rules
precede entry execution. The tools package has an empty search path; helpers
execute from the checked buffers, without fallback to an ordinary tools import.

`dependency_child_collection_request_v1` declares exactly one mode:

- `invented`: six sources (entry, evidence core, producer, collector, execution,
  invented operations). The input packet contains explicit invented file bytes,
  receipts and roots. It has no fallback to installed dependency reads.
- `runtime`: five sources; the invented helper is absent. The closed
  `runtime_dependency_packet_v1` accepts only expectation, package, binding,
  configuration text and cached-source text. It excludes supplied operations,
  callbacks and simulated contents. The concrete runtime observer is constructed
  internally only after Windows/CPython/startup/module checks. No valid runtime
  packet was launched in this qualification.

Both modes bind independently fixed policy/package/root declarations and a review
digest to the packet and exact source buffers. Runtime binding returns detached
validated groups and a copied exact-byte source map. A matching digest is a caller
declaration, not proof that a review occurred or permission to execute.

Preloaded ctypes/platform and fallback crypto modules are refused before and
after authored helper loading. Runtime preconditions precede collector filesystem
observations; the exact full runtime profile is checked by the child. Interpreter,
standard library and OS remain trusted rather than binary-attested.

## Evidence and result reconciliation

Complete collection checks 351 package files, five trusted origins and eleven
cached Python sources, preserving absolute receipts and relative projections.
The pure transition verifier binds the original package to the new receipt/proof
set. Collection and transition metadata are saved before dependency bootstrap.
The producer retains its fixed source/native rosters, public vectors and once-only
callback. Runtime grammar uses saved-record mode; tests of that grammar use
explicitly invented operations and do not establish actual observation.

The parent reopens the exact packet and source receipts after child exit, then
recomputes the saved collection, transition, six producer artifacts, verification
and completion. It checks the exact outer/inner file rosters and all eleven
artifact hashes against stdout. Self-consistent stdout substitutions alone do
not bypass those checks. Ordinary parent imports do not authenticate the executing
parent; parent authentication and review/operational authority remain false.

One exclusive attempt directory and one process launch are permitted. Timeout
terminates/reaps this host-only disposable process without restart. Uncertain
termination is recorded as needing process reconciliation. An interruption during
post-reap verification retains the known exit/PID and publishes `needs_review`;
the child is not replayed. Failed output publication still requires inspecting
the existing attempt; there is no universal automatic recovery.

## Qualification limits and next gate

Invented children install a real Python audit hook, then deliver simulated native
load events and use a public-vector lookup cipher. They execute no OS native
dependency loader. The retained audit hook is left inert in a reaped child.
Tests also exercise the saved-record grammar with FakeOps, whose nominal actual
flags cannot establish historical truth. Pure verifiers return false runtime and
producer authentication and no execution/feature/recovery/write authority.

and hardware behavior are not attested. Initial vector use precedes final guard
completion. The strict five-native roster, including AES-NI, is unchanged. Source
review and synthetic qualification do not observe an actual installation, create
