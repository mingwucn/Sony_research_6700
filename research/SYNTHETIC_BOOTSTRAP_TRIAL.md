## Bounded records and supervision

The typed JSONL journal distinguishes None, bool, integer, string, bytes, list,
tuple and dictionary. Exact builtins, depth, node and value bounds precede
serialization. At most 256 events, 4,096 bytes per complete line and 262,144 bytes
total are accepted. Each accepted event has one unbuffered write and fsync;
short writes, fsync failure and serialization failures remain sticky. Close is
attempted once. No ambiguous write is retried or overwritten. File fsync does
not establish parent-directory durability or event authenticity. These are
accepted-artifact limits, not peak-memory or whole-process limits.

The parent starts one child without a shell and drains both output pipes while
it runs. Each stream retains at most 65,536 bytes, reading at most the remaining
allowance plus one overflow byte, with individual reads capped at 4,096 bytes.
Overflow, timeout, I/O or cleanup errors stay failures even if exit zero follows.
Success requires observed zero exit, EOF and genuinely terminated reader threads.
Failure allows one kill/reap attempt and a shared two-second cleanup window;
unknown process completion preserves its PID for reconciliation. No retry occurs.
OS spawn/call latency, descendant processes and process memory are outside this
bound. Bounded raw stdout/stderr, journal, result and supervision facts remain
private; none is uploaded.

Recoverable `KeyboardInterrupt`/`SystemExit` now return sanitized interruption
facts through cooperative cleanup; [the current qualification](sessions/20261023-precontact-readiness.md)
adds thirteen mocked interruption cases. Attempts are recorded before calls,
the first failure remains sticky, and known PIDs are retained. An exception
before Popen returns is an unknown spawn outcome requiring process
reconciliation; it is not evidence that no child exists. No attempt is retried.
Repeated asynchronous interruption, abrupt process termination and OS call
latency remain outside the cooperative guarantee. This does not qualify actual
runtime activation, physical signals or device recovery.
