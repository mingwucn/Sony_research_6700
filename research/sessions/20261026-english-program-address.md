eight-byte inline value, with zero attributes and identical stored bytes.
The native schema code independently supports that interpretation. This is
packaged primary current-data content. It is not an owner-body readback,
proof that either catalog is selected, or evidence of a separate reset default.
The updater's destination manifest names a different catalog; that mismatch

The userspace Backup reader sends the full item and output pointer through a
specific synchronous operation. The native dispatch table selects the reader,
which looks up the record's full stored size. The caller's buffer capacity is
not an independent size limit. Conditional copy paths and ignored copy results
prevent treating a nominal returned size as proof that the output was filled.
The initializer's ignored read status remains a separate limit.

LIRO first rejects the zero address input, then converts a nonzero address using
an externally supplied memory-base value. Exact subtraction, comparison, mask
and conditional-selection operands were checked. Neither the current base nor
the resulting runtime pointer has been observed. The stored catalog number
therefore supplies no verified mapping to a file offset or program artifact.

The generic catalog initialization chain loads a file header, obtains a memory
pointer from that header, optionally reloads file contents according to a
parameter, and initializes the catalog data structures. The public-facing
storage path has configurable primary/secondary names and a load parameter.
