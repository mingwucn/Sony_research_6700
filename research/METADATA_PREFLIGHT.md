`prior_directory`, `prior_member_identification`, `prior_selection`,
`prior_measured`. Preserve every parsed field and exact built-in value/type;
never drop bookkeeping fields, round numbers, coerce values or compare with a
tolerance. Original JSON number spellings are not recoverable after parsing.

nonnegative float** values at the two observed root keys
`synthetic_unittest_seconds` and `real_elapsed_seconds`. Permit `-0.0` and
preserve its sign/representation using `float.hex()` comparisons. No other
float position, timing alias, subclass or nonfinite value is accepted. Integers
and booleans retain distinct exact types. These timing fields are ancillary
evidence bookkeeping; they never become offsets, lengths, identities or profile
permissions. This explicit change repairs the documented schema defect; it does
not relax a source, target, cryptographic or directory acceptance threshold.

per role. Reject cycles and non-string dictionary keys before copying. Serialize
with `allow_nan=False`; detach accepted trees and preserve all fields. No measured
or enforced whole-process memory cap, secure erasure or arbitrary callback sandbox
is claimed. Shared acyclic container aliases may become separate containers;
preserve values/types, without claiming alias identity or an atomic snapshot of
concurrently mutated caller containers.

actual firmware-source or operational-key I/O**. Reading authored code and preserved
metadata is allowed. A fresh measured object does not exist then. Validate
the seventh fresh `measured` role after the read through a separate full-input
preflight inside the gate. Structural preflight does not authenticate evidence,
validate lineage or create a supported target profile.

The original member/link acceptance, exact whole fresh measured-result equality,
source/stream/header/span/component-prefix checks, full directory equality,
selection and all-five prefix hashes/original outcomes must still run unchanged.
Expanded classification remains after every original check and observer cleanup.
Keep known candidate schema, order/ambiguity and all false feature/validation flags.

Add only fixed, closed role/stage diagnostics with no raw values, paths, member
names or exception text; a bounded attempted expanded-callback count may be recorded.
Preserve accumulated cleanup failure flags. A future
runner must place the prior-only structural preflight before actual input I/O,
