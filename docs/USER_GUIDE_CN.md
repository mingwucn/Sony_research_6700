本指南详细说明如何使用 **`Sony α6700 极简定制工具`** 为国行 Sony α6700（固件版本 **Ver. 2.00**）开启：
1. **原生完整 Wi-Fi FTP 传输**（包含 **网络 FTP 菜单 `0x05a5`–`0x05b0`** + 独家补齐的 **回放相册快捷键 `0x0817 FTP传输`**）

## 二、 运行前环境准备

### 1. 运行方式（二选一）

#### 选项 A：使用独立便携发布包（推荐 · 纯小白 · 无需安装 Python 环境）
1. 前往 **[GitHub Releases 页面](https://github.com/mingwucn/Sony_research_6700/releases/tag/v1.0.0)** 或点击 **[直接下载 Sony_a6700_Customizer_v1.0.0_win64.zip (~22.7 MB)](https://github.com/mingwucn/Sony_research_6700/releases/download/v1.0.0/Sony_a6700_Customizer_v1.0.0_win64.zip)**。
2. 下载解压至任意目录（体积约 22.7 MB，开箱即用）。
3. 解压后直接双击运行 **`SonyA6700Customizer.exe`**（或 **`启动_Sony_a6700定制工具.bat`**）。
4. 绿色免安装，内部已打包完整的 Python 运行时、WinUSB 通信驱动载荷与 AArch64 固件读写工具，任何 Windows 10/11 电脑均可直接运行。

#### 选项 B：源码运行（适合开发者）
1. **操作系统**：Windows 10 / Windows 11 (64 位)。
2. **Python 环境**：已安装 Python 3.10 或更高版本。
3. 双击根目录下的 **[`启动_A6700定制工具.bat`](file:///d:/LocalWork/Sony_research_6700/%E5%90%AF%E5%8A%A8_A6700%E5%AE%9A%E5%88%B6%E5%B7%A5%E5%85%B7.bat)**，脚本会自动校验环境并启动界面。
4. 开发者可通过运行 **[`打包独立发布版.bat`](file:///d:/LocalWork/Sony_research_6700/%E6%89%93%E5%8C%85%E7%8B%AC%E7%AB%8B%E5%8F%91%E5%87%86%E7%89%88.bat)**（或 `python tools/build_dist.py`）一键重新构建打包。

### 2. 相机端准备
1. **确认固件版本**：进入相机 `设置 (Setup) -> 版本 (Version)`，确认为 **Ver. 2.00**。
2. **确认电池电量**：请确保相机电池电量 **≥ 50%**（建议 80% 以上），切勿在低电量下操作。
3. **切换 USB 连接模式为【海量存储器 (MSC)】**：
   - 进入相机菜单：`设置 (Setup，黄色工具箱图标) -> USB -> USB连接模式 (USB Connection Mode)`
   - 选择 **`海量存储器 (Mass Storage)`**（不要选 MTP 或电脑遥控）。
4. **关闭冲突软件**：完全退出电脑上的 Sony Creators' App、Imaging Edge Desktop、Lightroom、捕获软件或任何正在运行的其它改机工具。

## 三、 针对曾用 Powerful6700 开启过 FTP 的用户：升级说明

很多 α6700 用户之前使用过 `Powerful6700` 工具开启了相机菜单里的网络 FTP，但在看图时发现无法设置快捷键一键上传，且英文菜单也没真正解锁。

**如果您此前已经用 Powerful6700 开启过 FTP，可以直接放心使用本工具升级：**
1. **智能识别提示**：在第 4 步只读检测时，本工具会自动检测到相机网络 FTP 已处于启用状态，并在界面明确提示：
   > *“检测到已开启基础网络 FTP（如曾使用 Powerful6700），回放快捷键未开启。本次勾选将为您无损补齐【回放快捷键 0x0817】，相机内原有的 FTP 服务器与 Wi-Fi 配置将被 100% 完整保留！”*
2. **零重复改写 (`no-op`)**：
   - Powerful6700 改写过的 9 处网络菜单标记在检测时已为 `01`，本工具在写入时会自动识别并直接跳过，绝不重复写入；
   - 仅会精准写入此前缺失的 **`0x03f17ce4`（回放相册自定义键权限位）** 以及 **`0x023080f8`（真原生英文菜单断言）**。
3. **相机内所有设置 100% 完整保留**：
   - 索尼相机中用户配置的 FTP 服务器地址、账号密码、上传目录和 Wi-Fi 连接信息均存储在 Backup NVRAM 专用配置区。
   - 本工具仅操作 `/usr/lib/appFw.so` 的程序代码与权限位，**绝不会破坏、重置或清除任何已保存的服务器配置**！
4. **一键出厂还原保护**：
   - 如果后续需要出厂还原，本工具的一键还原功能会将包括 Powerful6700 此前改写的 9 处网络位在内的全部 10 处 FTP 标志位统一还原为 100% 出厂原始状态。

## 四、 六步图形界面操作流程

双击项目根目录下的 **[`启动_A6700定制工具.bat`](file:///d:/LocalWork/Sony_research_6700/%E5%90%AF%E5%8A%A8_A6700%E5%AE%9A%E5%88%B6%E5%B7%A5%E5%85%B7.bat)** 启动深色模式桌面界面：

### 第 1 步：操作前须知
- 阅读安全说明，勾选 **“我已阅读上述须知，确认相机固件为 α6700 Ver. 2.00 且电量充足”**，点击 **“下一步：驱动检查”**。

### 第 2 步：Windows USB 驱动检查
- 点击 **“🔄 重新扫描驱动”**。
- **情况 A（已就绪）**：如果界面显示绿色 **`状态: WinUSB 驱动已就绪`**，说明你的电脑之前已经绑定好驱动，**无需重复安装**，直接点击右侧的 **“下一步：相机准备 ➔”** 即可（即使点击“一键绑定 WinUSB 驱动”，程序也会智能提示驱动已就绪并引导进入下一步）。
- **情况 B（未绑定）**：如果显示黄色未就绪，请先将开机状态的相机通过 USB-C 数据线连接电脑，然后点击 **“🛠️ 一键绑定 WinUSB 驱动”**，在弹出的管理员权限窗口中允许安装。

### 第 3 步：相机连接准备
- 确认相机已开机、处于 **海量存储器 (MSC)** 模式，并用可靠的 **USB-C 数据线** 连接到电脑主板原生 USB 接口。
- 点击 **“下一步：只读检测与备份 ➔”**。

### 第 4 步：相机只读检测与自动备份
- 点击 **“🔍 开始只读检查与备份”**。
- 工具将通过 USB 服务通道执行无损只读命令，读取 `/usr/lib/appFw.so` 中的 11 处目标偏移（共 14 字节）：
  - 自动校验每个字节是否符合 α6700 Ver. 2.00 原厂特征或已启用特征。
  - 自动在项目 [`backups/`](file:///d:/LocalWork/Sony_research_6700/backups/) 目录下生成带时间戳的备份文件（`a6700_backup_YYYYMMDD_HHMMSS.json`）以及初始原厂快照（`initial_backup.json`）。
- 检测成功后，界面会清晰列出：
  - **完整 FTP 传输（网络菜单 + 回放快捷键 0x0817）**：当前是 `[原厂未启用]` 还是 `[已启用]`
  - **原生英文菜单（Setup -> Language -> English）**：当前是 `[原厂未启用]` 还是 `[已启用]`

### 第 5 步：功能管理（勾选并一键写入）
- 勾选你需要开启的功能（默认两项全选）：
  - ☑️ **启用完整 FTP 传输（网络菜单 + 回放快捷键 0x0817）**
  - ☑️ **解锁原生英文菜单（Setup -> Language -> English）**
- 点击 **“⚡ 一键写入选中功能”**，并在确认弹窗中点击 **“是 (Yes)”**。
- **后台四重安全事务**：
  1. **只读复核 + 写前快照**：再次核对全部 11 个窗口字节并保存写前备份。
  2. **零改动写入探针 (Zero-Change Probe)**：先向 `0x023080f8` 写回其当前的原始字节并校验，验证闪存写入链路 100% 正常后才真正修改数据。
  3. **原子写入 + `fsync` 落盘**：通过 `flash_write.elf` 写入目标字节并强制刷新缓存到 NAND 闪存。
  4. **独立读回校验 (Read-Back Verification)**：重新读取全部修改位置，逐字节比对确认写入成功。
- **⚠️ 重要：重启相机生效**
  - 看到 **“功能写入并校验成功！”** 弹窗后：
  - 先将相机电源开关拨至 **OFF**，等待 **5 秒**（待存卡红灯完全熄灭）。
  - 拔掉 USB 数据线，**打开电池仓取出电池静置 5 秒**，再重新装入电池开机。

### 第 6 步：出厂还原（随时可逆）
- 如果日后需要将相机恢复为 100% 出厂状态（例如送修或升级固件前）：
  - 在第 4 步完成连接检测后，进入 **“6. 出厂还原”** 页面。
  - 点击 **“🔄 一键还原全部为原厂状态”**（或点击 **“📂 从备份文件还原...”** 选择任意历史 `.json` 备份）。
  - 注意：如果在相机里已经把界面语言切成了 English，建议先在相机菜单里切回 **简体中文**，再执行出厂还原。

## 四、 改机后相机端设置教程

### 1. 如何切换为原生英文界面 (`English`)
1. 开机按 `MENU` 键，进入最下方的 **`设置 (Setup，黄色工具箱图标)`**。
2. 选择 **`区域/日期 (Area/Date)` -> `语言 (Language)`**。
3. 此时列表第一项（原本被隐藏的槽位）已变为 **`English`**！
4. 选中 **`English`** 确认后，相机全套菜单、拍摄参数、报错弹窗、网络设置即刻切换为索尼官方原生英文界面，且随时可切回 **`简体中文`**。

### 2. 如何使用【相册回放选择传输】与【回放自定义键】上传 FTP

开启完整 FTP 后，除了在 **`网络 (Network) -> FTP传输 (FTP Transfer)`** 中配置你的手机/电脑 FTP 服务器外，相册回放支持两种传输体验（与 A7 IV / FX30 完全一致）：

#### 方式 1：相册回放菜单直接传输（Mode B）
1. 在看图回放状态下，按 `MENU` 键或 `Fn` 键，进入 **`播放 (Playback) -> 选择传输 (Select to Transfer)`**。
2. 此时原厂隐藏的传输菜单已全部解锁，你可以自由选择：
   - **此影像 (This Image)**：立即上传当前单张照片。
   - **多个影像 (Multiple Images)**：勾选多张照片批量上传。
   - **该组中所有影像 (All in This Group)**：连拍分组整组秒传。
   - **评级影像 (Rating Images)**：批量上传所有评级过的照片（如三星及以上）。
   - **传输设置**：可独立设置 `RAW+J/H传输目标`、`传输JPEG大小`、`传输HEIF大小`。

#### 方式 2：绑定【回放自定义键】一键盲操秒传（Mode A）
1. 按 `MENU` 键进入 **`设置 (Setup，黄色工具箱)` -> `操作自定义 (Operation Customize)`**。
2. 选择 **`回放自定义键设置 (PB Custom Key Setting)`**（英文界面下为 **`Custom Key/Dial Set.` (Playback)**）。
3. 选择你顺手的机身按键（强烈推荐绑定在 **`C1` 键（删除键）**、**`AF-ON` 键** 或 **`AEL` 键**）。
4. 在功能列表中找到 **`网络 (Network)`** 分类下的 **`FTP传输 (FTP Transfer)`** 并确认绑定。
5. **使用方式**：拍摄完成后按下回放键看图，看到满意的照片直接按一下刚刚绑定的快捷键，相机即刻将该张 RAW/JPEG 照片加入后台 Wi-Fi FTP 队列自动上传！

## 五、 常见问题排查 (FAQ)

### Q1: 在第 2 步点击“一键绑定 WinUSB 驱动”提示 `'int' object is not iterable`？
- **原因与解决**：该问题已在最新版本中彻底修复。同时请注意：如果界面上方已经显示绿色的 **`状态: WinUSB 驱动已就绪`**，说明你的电脑已经成功安装过驱动，**不需要**再点击安装按钮，直接点击 **“下一步：相机准备 ➔”** 或左侧导航栏第 3/4 步即可。

### Q2: 在第 4 步点击“开始只读检查与备份”提示 `No module named 'usb'`？
- **原因与解决**：这是因为系统的 Python 环境缺少 `pyusb` 和 `libusb-package` 模块。最新版本已在环境中安装完毕，并在 [`启动_A6700定制工具.bat`](file:///d:/LocalWork/Sony_research_6700/%E5%90%AF%E5%8A%A8_A6700%E5%AE%9A%E5%88%B6%E5%B7%A5%E5%85%B7.bat) 启动脚本中加入了自动检测安装逻辑。如遇此提示，直接双击运行 `启动_A6700定制工具.bat` 即可自动修复。

### Q3: 点击“开始只读检查与备份”时提示找不到相机或连接超时？
1. 检查相机是否处于开机亮屏状态（未进入自动休眠黑屏）。
2. 检查相机 `设置 -> USB -> USB连接模式` 是否明确设为 **`海量存储器 (Mass Storage)`**。
3. 检查是否使用了仅支持充电的 USB-C 线（请更换支持数据传输的 USB-C 数据线，并插在电脑后置主板 USB 口）。
4. 如果刚刚安装过 WinUSB 驱动，请拔插一次 USB 数据线并重启相机后再试。


### Q4: 这套原生英文解锁流程是否适用于国行 A7CR (`ILCE-7CR`) 和 A7M5 (`ILCE-7M5`)？
- **国行 A7CR (`ILCE-7CR`) —— ✅ 共享完全一致的解锁机制与执行流程**：
  - A7CR 与 α6700 同属 2023 代 **BIONZ XR (`CXD90057`)** 平台，共享相同的 `/dev/nflasha15` 分区、`/usr/lib/appFw.so`、`string_english*.uxc` 原生英文字库、`0x010d008f` 语言权限项以及 USB `Senser`/`Jiritsu` (`054C:0336`) 服务模式链路，因此同样适用 **`english_predicate` 4 字节补丁 (`f4 17 9f 1a` ➔ `34 00 80 52`)**。
  - **⚠️ 严禁直接将 α6700 工具用于 A7CR**：由于两款机型的 `appFw.so` 编译体积与偏移不同，适配 A7CR 时必须先在 A7CR 固件中定位其专属的 `english_predicate` 偏移（不可直接写入 α6700 的 `0x023080f8`），连接海量存储 PID `054C:0E8A`，并在写入后执行 `*wbi4` 快速启动镜像失效（`image_drop=1` ➔ `image_mode=0`）后冷启动。
- **国行 A7M5 (`ILCE-7M5` / Alpha 7 V) —— ❌ 当前不适用**：
  - A7M5 搭载了新一代 **BIONZ XR2** 处理器，索尼在 BIONZ XR2 平台上更新了 USB `Senser` 服务模式的挑战-响应鉴权协议（旧版握手会报 `Invalid response: 9` 或导致相机重启），因此在适配 BIONZ XR2 鉴权与解包密钥前无法共用本执行流程。
- 详细跨机型技术对比请参阅：**[`docs/CROSS_MODEL_ENGLISH_COMPARISON.md`](file:///d:/LocalWork/Sony_research_6700/docs/CROSS_MODEL_ENGLISH_COMPARISON.md)**。
