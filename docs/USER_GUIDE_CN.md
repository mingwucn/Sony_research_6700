# Sony α6700 极简定制工具 — 完整中文使用手册

本指南说明如何使用 **`Sony α6700 极简定制工具`** 修改国行 Sony α6700（固件 **Ver. 2.00**）的两组精确目标：
1. **FTP 菜单与动作**：网络 FTP 菜单 `0x05a5`–`0x05b0`、相册回放「选择传输」81 处权限、回放自定义键 Action `0x0817`。
2. **原生英文菜单** (`Setup -> Area/Date -> Language -> English`)：修改 4 字节语言谓词，使用相机原生英文资源，不改写中文字库、区域码或 Wi-Fi 频段配置。

**证据边界**：菜单与动作绑定已有固件静态分析和真机菜单回读证据；端到端上传、断线重连与长效网络传输仍需结合相机无线环境和 FTP 服务器持续验证。

## 一、功能与恢复设计

| 维度 | 本工具行为 |
| :--- | :--- |
| **目标范围** | 仅 `/usr/lib/appFw.so` 中 92 处目标，逻辑变化共 94 字节；不包含快门帘、曝光、声音、像素转换等实验功能 |
| **物理足迹** | 两项全选时计划处理 7 个独立段，共 236,018 字节（约 230.5 KiB），单段不超过 128 KiB；已是目标值的段可跳过 |
| **段内保留** | 其余 235,924 字节来自写前预读并原样保留，写入后执行全段逐字节比对，而非只检查修改点 |
| **持久日志** | 每次写前将完整原始/目标 `.bin` 快照 `fsync()` 到本机，并追加记录 JSONL 阶段事件 |
| **中断策略** | 超时、断连或校验不符立即进入 `NEEDS_REVIEW`，不盲目重试、不自动回退；启动后先只读对账 |
| **恢复边界** | 回退/续写和出厂还原都依赖 USB 服务模式及固件文件可访问；硬件损坏或固件不可访问时不保证软件层恢复 |

## 二、 运行前环境准备

### 1. 运行方式（二选一）

#### 选项 A：使用独立便携发布包（推荐 · 纯小白 · 无需安装 Python 环境）
1. 前往 **[GitHub Releases 页面](https://github.com/mingwucn/Sony_research_6700/releases/tag/v1.0.0)** 或点击 **[直接下载 Sony_a6700_Customizer_v1.0.0_win64.zip (~22.7 MB)](https://github.com/mingwucn/Sony_research_6700/releases/download/v1.0.0/Sony_a6700_Customizer_v1.0.0_win64.zip)**。
2. 下载解压至任意目录（体积约 22.7 MB，开箱即用）。
3. 解压后直接双击运行 **`SonyA6700Customizer.exe`**（或 **`启动_Sony_a6700定制工具.bat`**）。
4. 绿色免安装，内部已打包完整的 Python 运行时、WinUSB 通信驱动载荷与 AArch64 固件读写工具，任何 Windows 10/11 电脑均可直接运行。

#### 选项 B：源码运行（适合开发者）
1. **操作系统**：Windows 10 / Windows 11 (64 位)。
2. **Python 环境**：已安装 Python 3.10 或更高版本。
3. 双击根目录下的 **[`启动_A6700定制工具.bat`](file:///d:/LocalWork/Sony_research_6700/%E5%90%AF%E5%8A%A8_A6700%E5%AE%9A%E5%88%B6%E5%B7%A5%E5%85%B7.bat)**，脚本会自动校验环境并启动界面。
4. 开发者可通过运行 **[`打包独立发布版.bat`](file:///d:/LocalWork/Sony_research_6700/%E6%89%93%E5%8C%85%E7%8B%AC%E7%AB%8B%E5%8F%91%E5%87%86%E7%89%88.bat)**（或 `python tools/build_dist.py`）一键重新构建打包。

### 2. 相机端准备
1. **确认固件版本**：进入相机 `设置 (Setup) -> 版本 (Version)`，确认为 **Ver. 2.00**。
2. **确认电池电量**：请确保相机电池电量 **≥ 50%**（建议 80% 以上），切勿在低电量下操作。
3. **切换 USB 连接模式为【海量存储器 (MSC)】**：
   - 进入相机菜单：`设置 (Setup，黄色工具箱图标) -> USB -> USB连接模式 (USB Connection Mode)`
   - 选择 **`海量存储器 (Mass Storage)`**（不要选 MTP 或电脑遥控）。
4. **关闭冲突软件**：完全退出电脑上的 Sony Creators' App、Imaging Edge Desktop、Lightroom、捕获软件或任何正在运行的其它改机工具。

## 三、针对曾用 Powerful6700 开启过 FTP 的用户

1. 第 4 步会识别 `部分启用 (Partial)`：网络 FTP 已开启，但相册菜单或动作尚未全部开启。
2. 写前预读会逐目标判断；已符合目标值的字段不重复改写。仍需按所在完整段执行回读与保留校验，不能把逻辑字节数当作物理传输量。
3. 本工具可补齐 81 处相册权限、`0x03f17ce4` 动作位和 `0x023080f8` 英文断言。
4. FTP 服务器、账号、上传目录和 Wi-Fi 配置位于 Backup NVRAM。本工具目标仅为 `/usr/lib/appFw.so`，不主动读写或重置这些配置。
5. 第 6 页出厂还原会把本工具管理的全部 FTP 与英文字段写回 Ver. 2.00 预置值，包括其他工具此前改写的网络位；恢复仍以 USB 通信和固件可访问为前提。

## 四、 六步图形界面操作流程

双击项目根目录下的 **[`启动_A6700定制工具.bat`](file:///d:/LocalWork/Sony_research_6700/%E5%90%AF%E5%8A%A8_A6700%E5%AE%9A%E5%88%B6%E5%B7%A5%E5%85%B7.bat)** 启动深色模式桌面界面：

### 第 1 步：操作前须知
- 阅读 R4 固件修改风险与恢复边界，勾选确认后进入驱动检查。

### 第 2 步：Windows USB 驱动检查
- 点击 **“🔄 重新扫描驱动”**。显示绿色 **`状态: WinUSB 驱动已就绪`** 时无需重复安装。
- 未绑定时，连接开机相机，点击 **“🛠️ 一键绑定 WinUSB 驱动”** 并在管理员权限窗口中确认。

### 第 3 步：相机连接准备
- 确认相机开机、使用 **海量存储器 (MSC)**、可靠 USB-C 数据线直连电脑，并关闭其他相机访问程序。

### 第 4 步：相机只读检测与自动备份
- 点击 **“🔍 开始只读检查与备份”**。工具按 7 段读取 92 处目标，校验 Ver. 2.00 文件大小及目标字节状态。
- 时间戳 JSON 文件名为 `backup_a6700_YYYYMMDD_HHMMSS.json`。便携版保存在程序目录 `data/backups/`，源码运行保存在 `.data/customizer/backups/`。
- JSON 是目标状态记录；实际恢复使用的完整分段原始字节保存在写入会话的 `journals/sess_*/span_XX_stock.bin`，两者不可混同。

### 第 5 步：功能管理与顺序分段写入
- 勾选 FTP 菜单/动作和/或原生英文菜单。页面“写入范围与足迹披露”同时显示：
  - **94 个逻辑修改字节 / 92 处目标**；
  - 两项全选时 **7 段 / 236,018 字节（约 230.5 KiB）**的计划物理足迹；
  - 段内其余 **235,924 字节**来自预读并原样保留。
- 确认弹窗会按实际勾选重新计算逻辑字节、目标数和物理段足迹。明确批准后才会写入。
- 后台依次执行：完整段预读、原始/目标 `.bin` 快照 `fsync()`、零变化探针、独立段写入、全段逐字节回读。7 段不是原子整体；已完成段不会因后续段失败而自动撤销。
- 完成后安全断开 USB，关闭相机电源，等待存卡灯熄灭；按界面提示冷启动后在相机端验收菜单。菜单回读不等同于端到端网络传输验收。

### 第 6 步：有条件出厂还原
- 点击 **“🔄 还原管理字段为原厂预置值”**，将本工具管理的 FTP、动作和英文字段写回 Ver. 2.00 预置值并逐段校验。
- 当前版本没有“从 JSON 备份还原”按钮；中断会话回退使用第 7 页保存的原始 `.bin`。
- 还原依赖 USB 服务模式正常通信和固件文件可访问，不能保证硬件损坏或固件不可访问场景下的恢复。若已切换 English，建议先切回简体中文。

### 第 7 页：中断会话恢复与只读对账（条件启动）
- 启动时发现 `INITIALIZED`、`IN_PROGRESS`、`NEEDS_REVIEW` 或 `RECONCILED` 会话未闭环，应用自动进入本页。正常功能写入/还原则被安全锁定。
1. 连接相机后点击 **“🔍 开始只读对账扫描”**。此步骤只读取会话记录的段，不发送固件写入命令。
2. 查看每段分类：`UNTOUCHED_STOCK`（写前状态）、`FULLY_PATCHED`（会话目标状态）、`CORRUPTED_OR_PARTIAL`（异常/部分状态）。
3. **“🔄 回退全部修改段”**：预检所有必需的原始 `.bin`，复核设备自对账后未变化，再仅回退已修改/异常段并全段校验。
4. **“▶️ 续写未完成段”**：仅在无异常段时可用；跳过目标状态段，续写写前状态段。若所有段已达目标，则不写入并闭环会话。
5. 若对账后任何段变化、快照缺失、超时或断连，操作停止并重新锁定；必须重新只读对账，禁止盲目重复点击。

## 四、 改机后相机端设置教程

### 1. 如何切换为原生英文界面 (`English`)
1. 开机按 `MENU` 键，进入最下方的 **`设置 (Setup，黄色工具箱图标)`**。
2. 选择 **`区域/日期 (Area/Date)` -> `语言 (Language)`**。
3. 此时列表第一项（原本被隐藏的槽位）已变为 **`English`**！
4. 选中 **`English`** 确认后，相机全套菜单、拍摄参数、报错弹窗、网络设置即刻切换为索尼官方原生英文界面，且随时可切回 **`简体中文`**。

### 2. 如何使用【相册回放选择传输】与【回放自定义键】

在 **`网络 (Network) -> FTP传输 (FTP Transfer)`** 中配置服务器后，可使用以下菜单/动作入口。实际上传结果受文件格式、无线连接和服务器配置影响，应单独验收。

#### 方式 1：相册回放菜单（Mode B）
1. 在回放状态进入 **`播放 (Playback) -> 选择传输 (Select to Transfer)`**。
2. 已开放的入口包括：**此影像**、**多个影像**、**该组中所有影像**、**评级影像**，以及 `RAW+J/H传输目标`、JPEG/HEIF 传输大小等设置。
3. 选择后检查相机传输队列和服务器端文件完整性；不要仅凭菜单出现即认定上传成功。

#### 方式 2：绑定【回放自定义键】（Mode A）
1. 进入 **`设置 (Setup) -> 操作自定义 (Operation Customize) -> 回放自定义键设置 (PB Custom Key Setting)`**。
2. 选择机身按键（如 `C1`、`AF-ON` 或 `AEL`），在 **`网络 (Network)`** 分类下绑定 **`FTP传输 (FTP Transfer)`**。
3. 回放照片后按下绑定键，观察相机队列和服务器结果，验证当前照片是否按预期入队及完成传输。

## 五、 常见问题排查 (FAQ)

### Q1: 在第 2 步点击“一键绑定 WinUSB 驱动”提示 `'int' object is not iterable`？
- **原因与解决**：当前版本已修正该参数处理问题。如果界面已显示绿色 **`状态: WinUSB 驱动已就绪`**，无需重复安装，可继续后续步骤。

### Q2: 在第 4 步点击“开始只读检查与备份”提示 `No module named 'usb'`？
- **原因与解决**：源码运行环境缺少 `pyusb` 或 `libusb-package`。使用项目启动脚本检查依赖，或在隔离 Python 环境中安装项目依赖；独立便携版已内置运行时，不需要系统 Python。

### Q3: 点击“开始只读检查与备份”时提示找不到相机或连接超时？
1. 检查相机是否处于开机亮屏状态（未进入自动休眠黑屏）。
2. 检查相机 `设置 -> USB -> USB连接模式` 是否明确设为 **`海量存储器 (Mass Storage)`**。
3. 检查是否使用了仅支持充电的 USB-C 线（请更换支持数据传输的 USB-C 数据线，并插在电脑后置主板 USB 口）。
4. 如果刚刚安装过 WinUSB 驱动，请拔插一次 USB 数据线并重启相机后再试。


### Q4: 这套原生英文解锁流程是否适用于国行 A7CR (`ILCE-7CR`) 和 A7M5 (`ILCE-7M5`)？
- **国行 A7CR (`ILCE-7CR`) —— ✅ 共享完全一致的解锁机制与执行流程**：
  - A7CR 与 α6700 同属 2023 代 **BIONZ XR (`CXD90057`)** 平台，共享相同的 `/dev/nflasha15` 分区、`/usr/lib/appFw.so`、`string_english*.uxc` 原生英文字库、`0x010d008f` 语言权限项以及 USB `Senser`/`Jiritsu` (`054C:0336`) 服务模式链路，因此同样适用 **`english_predicate` 4 字节补丁 (`f4 17 9f 1a` ➔ `34 00 80 52`)**。
  - **⚠️ 严禁直接将 α6700 工具用于 A7CR**：由于两款机型的 `appFw.so` 编译体积与偏移不同，适配 A7CR 时必须先在 A7CR 固件中定位其专属的 `english_predicate` 偏移（不可直接写入 α6700 的 `0x023080f8`），连接海量存储 PID `054C:0E8A`，并在写入后执行 `*wbi4` 快速启动镜像失效（`image_drop=1` ➔ `image_mode=0`）后冷启动。
- **国行 A7M5 (`ILCE-7M5` / Alpha 7 V) —— ❌ 当前不适用**：
  - A7M5 搭载了新一代 **BIONZ XR2** 处理器，索尼在 BIONZ XR2 平台上更新了 USB `Senser` 服务模式的挑战-响应鉴权协议（旧版握手会报 `Invalid response: 9` 或导致相机重启），因此在适配 BIONZ XR2 鉴权与解包密钥前无法共用本执行流程。
- 详细跨机型技术对比请参阅：**[`docs/CROSS_MODEL_ENGLISH_COMPARISON.md`](file:///d:/LocalWork/Sony_research_6700/docs/CROSS_MODEL_ENGLISH_COMPARISON.md)**。
